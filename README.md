# Elysian_salon
A web application for managing salon appointments online. Customers can book services from the website, and I manage everything as the administrator through an admin panel.

📌 About the Project

This project simplifies salon operations by replacing manual bookings with an online system. Customers can view services and book appointments, while the admin can manage services, bookings, and customer records in one place.

✨ Features
Online appointment booking for customers
Admin panel to manage services, bookings, and customer records
Full CRUD operations
Responsive design for mobile, tablet, and desktop
MySQL database integration for efficient data management
🛠️ Built With
Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: PHP
Database: MySQL
